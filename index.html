    // 01 · Problem statement

    Signatures only know the past.

    Signature-based IDS match traffic against a library of known patterns. Novel or zero-day attacks match nothing — so they pass through undetected.

    IN

    Input

    Network connection records described by 41 engineered features — byte counts, error rates, service type, host-level traffic statistics.

    OUT

    Output

    A Normal / Attack classification, plus an anomaly score for traffic that matches no known signature.

    ∪

    Hybrid approach

    Supervised models for known attack signatures + an unsupervised autoencoder as a safety net for attacks never seen before.

    Try it: who catches what?

    40 incoming attacks. Dashed tiles are known families, solid-outlined tiles are zero-days.

      // 05 · Key ML concepts

      The ideas doing the heavy lifting.

      Precision vs recall · interactive

      Move the threshold, feel the trade-off.

      Precision: of everything flagged, how much was really an attack. Recall: of all real attacks, how many we caught. A missed attack costs more than a false alarm, so recall is prioritised.

      Precision
      Recall
      F1

      Supervised vs unsupervised

      Learning attacks vs learning normal

      LR, Random Forest and XGBoost learn from labelled examples — strong on known attacks. The autoencoder learns only “normal” and flags anything unfamiliar.

      Autoencoder reconstruction error

      Compress, rebuild, compare

      A network trained to squeeze normal traffic through a bottleneck and rebuild it. Attack traffic rebuilds poorly — that error is the anomaly signal (Xu et al., 2021).

      score(x) = ‖x − decoder(encoder(x))‖² / d
      Mutual information

      Ranking 41 features

      How much knowing one feature reduces uncertainty about the label.

      I(X;Y) = Σ p(x,y) log p(x,y) / p(x)p(y)
      Cross-validation

      5-fold CV

      Train on four folds, validate on the fifth, rotate. Confirms results aren’t a fluke of one particular split.

      score = mean(fold₁ … fold₅) ± sd
      Mann-Whitney U

      Is the difference real?

      Non-parametric test that normal and attack traffic differ on a feature by more than chance (p < 0.05). Live per-feature in the Lab.

      U = R₁ − n₁(n₁+1)/2

      // 08 · Project journey & work experience

      What we built, what we learned.

      The path from literature review to a working hybrid detector — and the roadmap beyond the mid review.

      Phase 01

      Literature & problem framing

      • Surveyed signature vs anomaly IDS
      • Chose NSL-KDD for its de-duplicated records and unseen-attack test split
      Lesson

      Headline accuracy hides failure on rare classes — define success as recall on unseen attacks.

      Phase 02

      Data engineering & EDA

      • Encoded protocol / service / flag
      • Log-scaled byte counts, train-only normalisation
      • Mann-Whitney U tests per feature
      Lesson

      Fitting the scaler on all data leaks test information — a classic pitfall (Arp et al., 2022).

      Phase 03

      Feature selection & supervised models

      • Mutual-information ranking of all 41 features
      • LR, Random Forest, XGBoost with 5-fold CV
      Lesson

      Trees excel on DoS / Probe, but R2L and U2R are rare and easily confused with normal sessions.

      Phase 04

      Autoencoder safety net

      • Trained on normal traffic only
      • Threshold from normal reconstruction-error percentile
      Lesson

      Unsupervised detection lifted unseen-attack recall from 27–47% to 78%.
